# G2.4/G2.9 ENSv2 runtime verification gate

Official current Sepolia ENSv2 deployment: [ENS deployments](https://docs.ens.domains/learn/deployments/), RootRegistry `0xb458d6a3a77919449d03e7a6903c26827c1ec43f`, ETHRegistry `0xd4ebcbbdf463c9c45784603db0ddd499bc44a8b4`. [Contracts-v2](https://github.com/ensdomains/contracts-v2/blob/main/contracts/README.md) documents PermissionedRegistry EAC and root-resource grants. These are the ENSv2 stack, not legacy ENSv1 NameWrapper.

Use `COMETENS_SEPOLIA_RPC_URL=https://<trusted-rpc> node scripts/g2-ensv2-sepolia-fork-evidence.mjs path/to/verified-pins.json`. Pin format: `{ "root": { "codeHash": "0x..." }, "eth": { "codeHash": "0x..." } }`; each may additionally specify `implementation:{ "address":"0x...", "codeHash":"0x..." }`. Obtain hashes independently from verified current deployment artifacts, not from the RPC being evaluated. The script reads at one finalized block and denies codehash/implementation/hierarchy changes. It performs no writes and does not claim ownership or exclusive rights even on success.
