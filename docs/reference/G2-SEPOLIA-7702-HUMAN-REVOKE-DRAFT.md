# Sepolia EIP-7702 owner revocation unsigned review draft

This optional CLI is **read-only**. It has no execute mode, wallet client, private-key access, authorization signatures or transaction broadcast. Use `node scripts/draft-g2-sepolia-7702-revoke.mjs check examples/g2-sepolia/04-revoke-7702.json`. The sample expiration is illustrative and must be replaced with a fresh timestamp (within one hour). The tool builds an unsigned plan after two independent RPCs agree on the existing delegation/runtime hash, confirmed and pending transaction nonce, and maximum fee budget. It embeds the EIP-7702 self-authorization expected nonce (`transaction nonce + 1`), zero-address target, and capability-loss warning. Any drift blocks the draft.

Actual self-signed EIP-7702 transaction sequencing, atomic fee bounds, revalidation between signing and broadcasting, and receipt/postcondition recovery are not sufficiently demonstrated in this repository. A planned follow-up must verify sender authorization and reliable type-4 broadcast end-to-end before offering an owner-operated execute command. Revoking delegation can disable smart-account sessions, recovery and automation; owner must explicitly consent using trusted independent wallet tooling. Do not use this unsigned output as executable authorization. The original salt and existing signer remain untouched.
