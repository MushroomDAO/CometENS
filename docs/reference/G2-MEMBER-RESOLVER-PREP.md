# G2.9 legacy ENSv1 member resolver change — unsigned draft

`scripts/prepare-legacy-member-resolver-change.mjs` encodes **only** the legacy Sepolia ENSv1 `NameWrapper.setResolver(node, nextResolver)` transaction for an actual wrapped member. It reuses the independently pinned and finalized snapshot observations in [G2 legacy native verifier](G2-LEGACY-HANDOFF-VERIFY.md), requires the member's existing ability to change their resolver to have been observed, rejects zero/unchanged new resolvers, and returns `chainId/from/to/data/value` for the **member's own wallet** to review, sign and broadcast *separately*. Neither script has a signer or write path.

The real NameWrapper implementation checks `onlyTokenOwner(node)` and `operationAllowed(node,CANNOT_SET_RESOLVER)` on execution. A finalized read is still a **stale snapshot** by the time a wallet transaction might be mined; approvals, NFT owner, parent expiry, ENSv2 migration and resolver permissions can change. Validate the actual transaction at execution and independently verify a finalized post-transaction resolver before crediting any native user autonomy. This draft itself never performs an ENS transaction, proves resolution reliability, or locks a record.

**Neither sovereign nor immutable:** `transactionSent=false`, `nativeHandoffCompleted=false`, `sovereignReceipt=false`, `lockedRecordVerified=false`, `ensV2AuthorityVerified=false` on every successful response. In particular, choosing a new mutable resolver or gateway is NOT proof that text/addr/contenthash has become irreversible. Locking records, if ever offered, is a separate explicit irreversible decision and requires an audited unupgradeable record store and full recoverability/expiry disclosure. ENSv2 Sepolia requires distinct EAC role and proxy-upgrade analysis, not legacy NameWrapper fuses.

This is a stacked G2.9 development companion to the read-only G2.7 verifier; both require separate exact-head reviewer/CI and eventual native ENS acceptance evidence. G2.7–G2.9 remain `PENDING` per [G2 acceptance matrix](../goal/G2-ACCEPTANCE.md).
