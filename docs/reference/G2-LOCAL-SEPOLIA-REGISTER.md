# G2 Sepolia register/reveal: gated local validation

This branch adds a strict `register` JSON (`examples/g2-sepolia/03-register.json`) and a dual-provider read-only preflight. It **does not authorize execute**. `node scripts/g2-local-sepolia-register.mjs execute ...` exits before loading credentials or opening a wallet. It never signs or broadcasts. The current user's existing salt and commitment are read without modification; the program does not create salt. The existing `prepare-g2-sepolia-ensv2-registration.mjs` validates the official registrar's `register(string,address,bytes32,address,address,uint64,address,bytes32)` ABI, chain ID, current commitment age, price, runtime hashes, allowance/balance, token acceptance, gas, and dry-run before this gate compares two RPC snapshots. A disagreement or expired/missing commitment remains blocked.

Prime's verified low-level `eth_call` revert `0x57f447ce` decodes as `ERC1155InvalidReceiver(0xF7Bf79AcB7F3702b9DbD397d8140ac9DE6Ce642C)`, **not** an allowance error. The intended receiver wallet has EIP-7702 delegation bytecode `0xef01005804b6119d12ad403a430fd3cff12a8ff6e4064b`, targeting `0x5804b6119d12ad403a430fd3cff12a8ff6e4064b`; the delegated `onERC1155Received` read-only call reverts. The CLI now checks wallet code on both RPCs and returns `EIP7702_DELEGATION_ACTIVE` for this state, or blocks unknown code/disagreement. **Only the wallet owner may explicitly clear that delegation.** No agent must submit a delegation change. Execution remains disabled pending owner action, fresh successful onchain checks and independent review. Never copy/register/reveal a secret or transact based on this draft.

`check` is read-only. The 60-second minimum commitment age and 24-hour maximum are obtained from live registrar reads, not assumed. The existing registrar has no `maxCost` argument: approval bounded at or below 9,000,000 base units can constrain ERC20 spending, but price and allowance can change before inclusion. TTY prompts also cannot establish that a human is controlling the terminal. The eventual register signer requires its own independent implementation and review once the revert is resolved.
