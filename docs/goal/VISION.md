## 用户 2026-10-20 复审需求（整理，原始七项保持逐字不变）

1. SDK 需要后台 API URL、API key 和一系列可替换的合约地址。
2. AAStar 默认提供多签治理的服务合约与一定免费额度。
3. 提供文档让自部署用户可以完整替换 API、网关及合约。
4. 在交权最终阶段，运营方跑路、密钥泄漏或自身合约遭攻击也不能重新控制用户原生 ENS 产权或篡改受保护的解析记录；临时超级管理员必须在生产初始化后移交或销毁，所有权边界要有可复跑证明。
5. 早期运营代管可允许覆写/回收，但应明确提示并最终完成真正交权。
6. 社区多签持有 communityxxx.eth，分配 jason.communityxxx.eth 或管理已授权的下一层命名空间；需要评估不可篡改、不可收回、解析续存的前提及可选公共续费安全基金。
7. 为当前、ENSv1 最终交权及 ENSv2 未来体系提供至少三张 Mermaid 架构图、状态机、故障兜底与测试证据，并持续写入 progress。

以上为新复审要求的**归纳**，完整方案见 [SECURITY-AND-SERVICE.md](SECURITY-AND-SERVICE.md)，不改写上方原始七项目标。
